# Heimatinventur

Haushalts-Inventur (Bestand, MHD, Lagerorte, Einkaufsliste, Statistik) als Web-App.

- App: GitHub Pages (`index.html`, `backend.js`, `lib/`)
- Daten: Supabase (Tabelle `docs`, Zugriff nur für E-Mails in `members`)
- Einrichtung der Datenbank: `schema.sql` im Supabase SQL Editor ausführen.
